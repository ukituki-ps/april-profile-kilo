# ADR-0001: Ведение Architecture Decision Records

- **Дата:** 2026-04-10
- **Статус:** принято
- **Контекст:** Нужна прозрачная история существенных архитектурных решений в монорепозитории, согласованная с документацией (Docusaurus, OpenAPI, C4).
- **Решение:** Вести ADR в каталоге `docs/adr/`, публиковать на сайте документации, использовать шаблон `template.md` и индекс в `README.md`.
- **Последствия:** Решения проще находить и пересматривать; требуется дисциплина обновления индекса и статусов.

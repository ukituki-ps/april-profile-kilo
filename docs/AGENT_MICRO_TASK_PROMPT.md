# AGENT MICRO TASK PROMPT

Использование: скопируй блок ниже в чат агента и вставь микро-задачу в секцию `TASK START/END`.

```md
Ты работаешь в репозитории April. Выполняй задачу строго по правилам проекта.

# Обязательные шаги перед реализацией
1. Прочитай и соблюдай: `docs/AGENT_MASTER_PROMPT.md`.
2. Если нужно, прочитай связанные правила в `.cursor/rules/`.
3. Ничего не пропускай из обязательных требований master prompt.

# Формат для маленьких задач (micro-task)
Если задача маленькая и для нее еще нет папки в `tasks/`, создай:
- `tasks/<NNN-or-date>-micro-<slug>/TASK.md`
- `tasks/<NNN-or-date>-micro-<slug>/REPORT.md`
- `PLAN.md` создавай только если задача нетривиальная.

Содержимое `TASK.md` сделай по компактному шаблону:
- Мета (id/ветка, приоритет, связанные файлы)
- Цель
- Scope (что входит / что не входит)
- AGENT_MASTER_PROMPT compliance checklist
- Acceptance criteria
- Проверка (конкретные команды)
- Ожидаемый результат в REPORT

# Выполнение
Сделай задачу end-to-end:
анализ -> изменения в коде/доках -> тесты/линт/сборка (релевантные) -> обнови `REPORT.md`.

# Требования к отчету (`REPORT.md`)
Укажи:
- что изменено (файлы и суть),
- какие проверки выполнены и их результат,
- риски/ограничения,
- follow-up (если есть).

# Ограничения
- Следуй DS-first.
- Не расширяй scope без явного запроса.
- Не делай destructive git-команды.
- Не пропускай обязательные проверки без объяснения причины в REPORT.

--- TASK START ---
<ВСТАВЬ СЮДА САМУ МИКРО-ЗАДАЧУ ЧЕЛОВЕЧЕСКИМ ЯЗЫКОМ>
--- TASK END ---
```

# Шаблон детального плана по задаче (April)

Назначение: зафиксировать **как** решать задачу до или в начале реализации — шаги, затрагиваемые области репозитория, проверки и риски. Файл сохраняется в подпапке задачи как **`tasks/<NNN-slug>/PLAN.md`** (см. [`tasks/README.md`](../tasks/README.md)).

Когда создавать: для нетривиальных задач (несколько файлов/слоёв, неочевидный порядок работ, зависимости). Для мелких правок достаточно постановки в `TASK.md` без отдельного плана.

Связь с процессом: общий алгоритм — [`AGENT_STEP_BY_STEP_PLAN.md`](./AGENT_STEP_BY_STEP_PLAN.md); постановка — [`AGENT_TASK_TEMPLATE.md`](./AGENT_TASK_TEMPLATE.md).

## Пояснения

| Раздел | Зачем |
|--------|--------|
| **Допущения** | Явно зафиксировать то, от чего строится план (версии, стенд, согласованный scope). |
| **Шаги** | Воспроизводимый порядок: зависимости между слоями, миграции до кода и т.п. |
| **Области** | Быстрый обзор blast radius для ревью и онбординга. |
| **Риски** | То, что чаще всего забывают до инцидента. |
| **Проверка** | Согласование с критериями приёмки в `TASK.md`. |

План можно уточнять по ходу работы; существенные изменения scope лучше отразить в `TASK.md` и здесь (или пометить план как устаревший).

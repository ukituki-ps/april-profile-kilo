# Шаблон отчёта агента о выполненной задаче (April)

```md
## 1) Итого
- Статус: [✅ выполнено | ⚠️ частично | ❌ не выполнено]
- Задача: <краткое название>
- Ветка: `<branch>`
- Коммиты: `<hash1>`, `<hash2>`
- PR: <url или "не создавался">

## 2) Что сделано
- [backend] …
- [frontend] …
- [infra / compose / nginx] …
- [docs] …

## 3) Изменённые файлы
- `path/file1`
- `path/file2`

## 4) Миграции и данные
- Миграции Atlas: [добавлены / нет]
- Какие таблицы/индексы изменены: …
- Обратимость: [да / нет; как откатить]

## 5) Проверка качества
- Линтер: [ok / fail]
- Сборка: [ok / fail]
- Unit tests: [ok / fail]
- Integration tests: [ok / fail]
- E2E / smoke: [ok / fail]

Команды (фактически выполненные):
```bash
<command 1>
<command 2>
```

## 6) Деплой
- Среда: [dev (`DEV_HOST`) / нет / другое]
- Согласовано с: [`docs/DEPLOYMENT_STRATEGY.md`](./DEPLOYMENT_STRATEGY.md)
- Образы: [теги по git SHA в ghcr / не применялось]
- Health / readiness: [проверка по внутреннему порту; при наличии маршрутов — `/healthz`, `/readyz` или что зафиксировано в API]
- Rollback: [нет / да, причина и действия]

## 7) Риски и ограничения
- …

## 8) Что осталось
- [ ] …
```

# Шаблон задачи для отработки агентом (April)

Использование: скопируй блок **«Заполнение»** в чат Cursor (или в issue/PR), удали неприменимые поля, заполни остальное. Для полноформатной задачи заведи подпапку в [`tasks/`](../tasks/README.md) (например из [`tasks/_template/`](../tasks/_template/TASK.md)) и сохраняй постановку в `TASK.md`. Для нетривиальных задач дополнительно заведи **`PLAN.md`** в той же подпапке по [`AGENT_PLAN_TEMPLATE.md`](./AGENT_PLAN_TEMPLATE.md). Перед работой агент сверяется с [`AGENT_MASTER_PROMPT.md`](./AGENT_MASTER_PROMPT.md), [`AGENT_ARCHITECTURE_CONTEXT.md`](./AGENT_ARCHITECTURE_CONTEXT.md) и при необходимости с [`DEPLOYMENT_STRATEGY.md`](./DEPLOYMENT_STRATEGY.md) / [`TESTING_STRATEGY.md`](./TESTING_STRATEGY.md).

## Пояснения к разделам

| Раздел | Зачем |
|--------|--------|
| **Мета** | Отслеживание задачи и связь с [`task_list.md`](../task_list.md) / веткой. |
| **Цель** | Одна мысль — меньше разночтений. |
| **Контекст** | `@файлы` в Cursor дают агенту актуальный код без догадок. |
| **Входит / не входит** | Фиксация границ scope. |
| **Ограничения** | Стек April, Atlas для БД, Keycloak для RBAC, безопасность. |
| **Критерии + команды** | Объективная приёмка и воспроизводимость. |
| **Результат** | Удобный handoff после сессии агента. |
| **История в docs-site** | Понятное для людей описание результата задачи и практической пользы. |

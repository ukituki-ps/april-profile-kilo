## Правило Tree ↔ Source (реализовано)

- Источник истины для сохранения — объект `Record<string, unknown>`; в режиме **Source** хранится отдельная строка, синхронизируемая при переходе **Tree → Source** (`JSON.stringify` текущего объекта).
- Переход **Source → Tree**: парсинг всей строки; при ошибке переключение блокируется, показывается `Alert` с текстом ошибки.
- **Save / Create**: если активен Source, перед вызовом API выполняется тот же парсер; при ошибке операция не уходит на сервер, показывается сообщение в существующем `mutationMessage`.

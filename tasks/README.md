# Папка задач

Каждая задача — отдельная подпапка: постановка, отчёт и всё сопутствующее лежат рядом.

## Именование папок

Рекомендуемый формат: `NNN-<краткий-slug-latin>`, например `001-bootstrap`, `042-health-endpoint`. Префикс `NNN` задаёт порядок и уникальность; slug — по смыслу задачи.

Мелкие (micro) задачи используют **тот же** сквозной префикс `NNN`, а не отдельную нумерацию и не дату в имени папки: `060-micro-…` вместо параллельного ряда вроде `20260430-micro-…`. Следующий номер — по максимальному уже занятому `NNN-` среди всех подпапок в `tasks/`.

Шаблон для копирования: [`_template/`](./_template/).

## Содержимое подпапки

| Файл / каталог | Назначение |
| -------------- | ---------- |
| `TASK.md` | Постановка: цель, scope, критерии приёмки (см. [`docs/AGENT_TASK_TEMPLATE.md`](../docs/AGENT_TASK_TEMPLATE.md)) |
| `PLAN.md` | Детальный план решения: шаги, затронутые области, риски, проверки (см. [`docs/AGENT_PLAN_TEMPLATE.md`](../docs/AGENT_PLAN_TEMPLATE.md)); для нетривиальных задач — до или в начале работы |
| `REPORT.md` | Отчёт после выполнения (см. [`docs/AGENT_REPORT_TEMPLATE.md`](../docs/AGENT_REPORT_TEMPLATE.md)) |
| `notes.md` | Опционально: черновики, решения в процессе |
| `attachments/` | Опционально: скриншоты, выгрузки, ссылки в виде файлов, мелкие артефакты |

Индекс крупных задач по репозиторию — в [`task_list.md`](../task_list.md).

## Риски и откат
- **Риск:** флейки в async UI-тестах.  
  **Митигация:** стабилизация ожиданий, контроль таймаутов, устранение race в тестовом коде.
- **Риск:** слишком тяжелый gate замедлит разработку.  
  **Митигация:** разделение на blocking и non-blocking проверки с явным списком.
- **Риск:** расхождение между docs и CI-фактом.  
  **Митигация:** описывать только реально выполняемые команды.
- **Откат:** откат test/docs изменений 047 целиком, если выявлены неприемлемые флейки; переоткрыть задачу с планом стабилизации.

  - `cd frontend && npm run test -w @april/profile-ui`

- Ручной smoke:

# 000 — Дорожная карта сервиса + интеграция AprilHub

## Что это дало

Команда получила не "список хотелок", а последовательный план, в каком порядке превращать шаблон в рабочий сервис.

## Что зафиксировали

- Фазы развития (с зависимостями между задачами).
- Границы между "делаем сейчас" и "потом".
- Точки стыковки с AprilHub (OIDC, деплой, observability, smoke).
- Критерии, по которым считаем этап выполненным.

## Почему это важно

Без roadmap легко начать "всё сразу":

- внедрять фичи раньше инфраструктуры,
- ломать очередность миграций и деплоя,
- терять прозрачность для ревью и планирования.

Roadmap снимает эти риски и делает прогресс измеримым.

## На выходе

- Понятная очередность задач 0 -> 1 -> дальше.
- Осознанный путь до production-grade контура.
- База для синхронизации backend/frontend/infra работ.

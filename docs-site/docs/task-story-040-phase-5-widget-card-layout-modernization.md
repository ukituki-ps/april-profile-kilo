# 040 — Двухколоночный `widget-card` для работы с профилями

## Какая была проблема

Старый интерфейс списка профилей и карточки работал как единый длинный блок: оператору было сложнее быстро переключаться между профилями и одновременно видеть детали выбранного объекта. Создание нового профиля тоже было встроено в основной поток и визуально отвлекало от текущей карточки.

## Что сделали

- Перестроили `widget-card` (реализация в `ProfilesListWidget`) в формат master-detail 25/75:
  - слева колонка списка профилей;
  - справа карточка выбранного профиля.
- Для левой части использовали DS-компонент `CardListColumn` из `@april/ui` (DS-first).
- В левой колонке оставили ключевые сценарии оператора:
  - поиск;
  - фильтр по типу профиля;
  - догрузка списка по достижению конца колонки (`onReachListEnd`, как в showcase);
  - явное выделение выбранного профиля.
- Создание нового профиля вынесли в модальное окно, которое открывается по кнопке "плюс" в колонке списка.
- Добавили/обновили RTL-тесты на сценарии выбора, поиска/пагинации, create/update/delete и безопасное отображение API-ошибок.

## Что это даёт команде и пользователям

- Быстрее навигация по профилям: список всегда под рукой, детали не теряются.
- Чище UX: создание нового профиля не ломает контекст текущего просмотра.
- Меньше риска регрессий: поведение покрыто тестами для основного CRUD-потока и ошибок API.

## Как проверить без чтения кода

1. Запустить frontend-проверки: `cd frontend && npm run lint && npm run test && npm run build`.
2. В демо виджета убедиться, что интерфейс разделён на две области 25/75.
3. Проверить слева поиск/фильтр/дозагрузку списка и выбор карточки.
4. Нажать кнопку "плюс", создать профиль в модалке и убедиться, что он появляется в списке и становится выбранным.
5. Проверить редактирование выбранного профиля справа и корректные сообщения для API-ошибок.

## Границы и follow-up

- В рамках задачи не менялись backend-контракты и OpenAPI.
- Не менялась IAM-модель (Keycloak/RBAC остаётся серверной ответственностью).
- Не выполнялся редизайн других виджетов вне `widget-card`.
